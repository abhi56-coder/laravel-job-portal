# Features

## Candidate Features

- Candidate registration
- Candidate login
- Candidate profile
- Resume upload
- Search jobs
- Filter jobs by location, role, salary, and experience
- Apply for jobs
- Track application status
- Save jobs

## Employer Features

- Employer registration
- Employer login
- Company profile
- Create job posts
- Edit job posts
- View applicants
- Shortlist or reject applications

## Admin Features

- Manage candidates
- Manage employers
- Approve or reject job posts
- View all applications
- Dashboard summary

## Job Features

- Job title
- Job description
- Company name
- Location
- Salary range
- Experience level
- Skills required
- Job status

## Future Enhancements

- Email notifications
- Resume parsing
- Job recommendation system
- Payment plan for employers
- React frontend
