# Laravel Job Portal

A Laravel-based job portal project for candidates, employers, job listings, applications, resume uploads, and admin review.

## Project Goal

This project is designed to demonstrate practical Laravel development skills through a real-world recruitment platform workflow.

## Tech Stack

- Laravel 10/11
- PHP 8+
- MySQL
- Blade / Bootstrap
- React optional in phase 2
- Git + GitHub

## Planned Features

- Candidate registration and login
- Employer registration and login
- Admin dashboard
- Job posting management
- Job search and filters
- Resume upload
- Apply for jobs
- Application status tracking
- Employer applicant review
- Admin approval workflow

## Main Modules

1. Authentication
2. Candidate Dashboard
3. Employer Dashboard
4. Job Listings
5. Job Applications
6. Resume Uploads
7. Admin Review
8. Search and Filters
9. Reports

## Database Tables

- users
- candidate_profiles
- employer_profiles
- jobs
- job_applications
- resumes
- saved_jobs

See `docs/database-schema.md` and `database/schema.sql`.
